# إعداد اتصال متصفح DAZZA

واجهة الويب القديمة تستدعي بوابة الهوية من المتصفح، لذلك يجب السماح بأصل الويب عبر CORS.

أضف إلى ملف بيئة الخادم .env:

    WEB_ORIGINS=https://your-web-domain.example

للتطوير المحلي فقط يمكن استخدام:

    WEB_ORIGINS=http://localhost:5173,http://127.0.0.1:5173

لا تستخدم * في الإنتاج. أعد تشغيل خدمة gateway بعد تعديل البيئة. لا تضع مفتاح Resend أو أسرار تسجيل Matrix في إعدادات الواجهة.
