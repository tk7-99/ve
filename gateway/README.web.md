# إعداد اتصال متصفح DAZZA

واجهة الويب تستدعي بوابة الهوية من المتصفح، لذلك يجب السماح بأصل الويب عبر CORS.

أضف إلى ملف بيئة الخادم `.env`:

```dotenv
WEB_ORIGINS=https://your-web-domain.example
```

للتطوير المحلي فقط يمكن استخدام:

```dotenv
WEB_ORIGINS=http://localhost:5173,http://127.0.0.1:5173
```

لا تستخدم `*` في الإنتاج. أعد تشغيل خدمة gateway بعد تعديل البيئة. لا تضع أسرار Twilio أو أسرار التسجيل في إعدادات الواجهة.
