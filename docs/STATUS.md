## سير التسجيل بالبريد

1. يدخل المستخدم بريده.
2. يرسل الخادم رمز تحقق عبر Resend.
3. يدخل المستخدم الرمز.
4. الحساب الموجود يدخل مباشرة دون اسم أو اسم مستخدم جديد.
5. الحساب الجديد يضيف الاسم واسم المستخدم الفريد مرة واحدة.
6. ينشئ الخادم جلسة Matrix ويعيدها إلى التطبيق.

مسارات الهاتف وTwilio أزيلت من خدمة الهوية؛ البريد هو وسيلة التسجيل والدخول الوحيدة في هذا الإصدار.

## ما لم يتم إثباته

- لم يثبت وصول رسائل Resend فعلياً، ولم تُربط أسرار Resend بالخادم من خلال المستودع.
- لا توجد نتيجة اختبار Docker أو خادم منشور في هذه المهمة.
- لم يُبنَ APK أو IPA في هذه المهمة.
- لم يُختبر تسجيل حسابين حقيقيين أو المراسلة بين جهازين.
- المكالمات والحالات والقنوات والإشعارات الخلفية ولوحة الإدارة غير منفذة.

لا تستخدم هذه النسخة لإدارة محادثات حساسة أو للإطلاق العام قبل إكمال اختبارات التشفير واستعادة المفاتيح ومراجعة الأمن.
