# بنية DAZZA

## المسار المختار

Flutter أصلي يتصل مباشرة بخادم Matrix/Synapse عبر HTTPS للمراسلة والمزامنة. بوابة FastAPI مستقلة تخص تسجيل الهاتف وحجز اسم المستخدم فقط. PostgreSQL هو التخزين الدائم، وRedis يحتفظ بتحديات التحقق قصيرة العمر وحدود المحاولات. Caddy يعزل واجهات الخدمات العامة وينهي TLS. لم تُستخدم قاعدة Teable أو مصادقة منشئ الويب.

```text
Flutter ── HTTPS ── Caddy ── Matrix Client API ── Synapse ── PostgreSQL (synapse)
   │                                             │
   │                                             └─ encrypted media volume
   └────── HTTPS ── Caddy ── FastAPI ── Twilio Verify
                              │
                              ├─ Redis (OTP challenge / cooldown / attempts)
                              ├─ PostgreSQL (dazza_identity.profiles)
                              └─ internal-only Synapse registration/login
```

## الهوية

1. الهاتف يُطبّع إلى E.164؛ العراق هو البلد الافتراضي، ويمكن إدخال مفتاح دولي آخر.
2. يفرض الخادم حد إعادة إرسال 60 ثانية، وخمس رسائل لكل هاتف في الساعة، وعشر لكل عنوان IP، وعشر محاولات رمز خلال عشر دقائق.
3. يرسل Twilio Verify الرمز. لا يُولد الخادم رمزاً بديلاً ولا يتجاوزه في وضع التطوير.
4. يحتفظ Redis بالهاتف داخل تحدٍ عشوائي لمدة خمس دقائق. PostgreSQL يحتفظ ببصمة HMAC للهاتف وليس الهاتف نفسه. هذه بصمة اسم مستعار وليست ضمان إخفاء هوية كاملاً.
5. نجاح التحقق يستهلك التحدي، ثم يحجز اسم المستخدم داخل معاملة PostgreSQL. اسم المستخدم فريد وغير قابل للتغيير في هذا الإصدار.
6. يُنشأ حساب Matrix غير إداري عبر التسجيل السري على الشبكة الداخلية. كلمة مروره مشتقة بمفتاح خادم مستقل؛ لا تُرسل للهاتف. كل دخول ينشئ جهاز Matrix وجلسة حقيقية.
7. البحث عن المستخدمين يتحقق من جلسة Matrix أولاً. لا توجد واجهة عامة تعرض أرقام الهواتف.

عند اختيار اسم محجوز بعد نجاح OTP، يلزم طلب رمز جديد. عند انقطاع خدمة لاحقة بعد استهلاك الرمز، يلزم أيضاً رمز جديد. هذا مقصود لمنع إعادة تشغيل إثبات الدخول، لكنه يحتاج تحسين تجربة إكمال التسجيل.

## المراسلة والتشفير

Matrix يدير الأحداث والعضوية والصلاحيات والأجهزة ومفاتيح Olm/Megolm. عميل Flutter يستخدم Matrix SDK وVodozemac. يُفعّل التشفير عند إنشاء المحادثة، وتتحقق واجهة الإرسال من حالة التشفير قبل إرسال نص أو ملف. الوسائط تُرفع عبر دالة SDK المخصصة للتشفير.

المزامنة تستخدم بروتوكول Matrix `/sync` طويل الانتظار بدلاً من WebSocket مخصص. تخزين العميل المحلي مشفّر عبر SQLCipher، والمفتاح في Secure Storage. لا يوجد تشفير رسائل مكتوب خصيصاً لهذا المشروع.

لم تُبنَ واجهة التحقق المتبادل من الأجهزة أو النسخ الاحتياطي للمفاتيح. لا تخلط حالة `sent/synced` مع إثبات التسليم لجهاز المستلم أو القراءة. الواجهة الحالية تسمي نجاح الإرسال «أرسلت للخادم» فقط. واجهة إيصالات القراءة الكاملة وقائمة إعادة المحاولة تحتاج إكمالاً.

## مطابقة البيانات المطلوبة

لا تُنشأ جداول رسائل مكررة بجانب مخطط Synapse؛ تكرارها قد يتجاوز بروتوكول التشفير ويؤدي إلى تعارض المزامنة. Synapse ينشئ مخططه وترحيلاته بنفسه.

| المجال المطلوب | مكانه في البنية | حالة ربط DAZZA |
|---|---|---|
| Users / UserProfiles | هوية Matrix وملفها + profiles في قاعدة الهوية | دخول، اسم مستخدم واسم عرض؛ بقية الملف غير مكتملة |
| Conversations / ConversationMembers | Rooms وMembership events | فردي ومجموعات ودعوات |
| Messages / MessageReactions | Matrix events وعلاقات الأحداث | إرسال وتعديل ورد وتفاعل؛ عرض العلاقات غير كامل |
| MessageAttachments | encrypted Matrix media | رفع وتنزيل ملفات، دون مشغلات صوت/فيديو مخصصة |
| Groups / GroupMembers | الغرف الخاصة وصلاحيات العضوية | إنشاء ودعوة؛ واجهات الإدارة المتقدمة غير منفذة |
| Devices / Sessions | Matrix devices وaccess tokens | إنشاء جلسة وتخزين آمن؛ شاشة إدارة الأجهزة غير منفذة |
| UserSettings | SharedPreferences لإعدادات محلية غير حساسة | لغة وثيم وحجم خط |
| Contacts / FriendRequests / BlockedUsers / Reports | امتداد علاقات واعتدال مطلوب | غير منفذ |
| Calls / CallParticipants | Matrix signaling + WebRTC + TURN مخطط | غير منفذ |
| Stories / StoryViews | خدمة حالات بصلاحيات وانتهاء زمني مخططة | غير منفذ |
| Communities / Channels / ChannelSubscribers | Matrix spaces / broadcast rooms مخطط | غير منفذ |
| Notifications | push gateway وFCM/APNs مخطط | غير منفذ |

## الحدود التشغيلية

- خدمات PostgreSQL وRedis وSynapse لا تُنشر منافذها مباشرة على المضيف.
- واجهات Synapse الإدارية لا تمر عبر Caddy.
- الصلاحيات التفصيلية للمجموعات مطبقة في بروتوكول Matrix، لكن واجهات إدارة DAZZA لم تُستكمل.
- التكوين الحالي مفرد الخادم. لا يتضمن clustering أو autoscaling أو تخزيناً كائنياً أو خطة تعافٍ مختبرة.
- لا يوجد TURN أو WebRTC أو لوحة إدارة ضمن التنفيذ الحالي. لا تكفي إضافة زر اتصال أو اسم خدمة في Docker لاعتبارها منجزة.
- قبل الإنتاج: فصل مستخدمي قواعد البيانات، فحص صور الحاويات واعتماداتها، مراجعة السجلات وقيود الموارد، نسخ احتياطية مشفرة مع تجربة استعادة، وإعداد مراقبة لا تجمع محتوى الرسائل.
