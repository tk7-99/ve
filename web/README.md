# DAZZA Web — دَزّة

واجهة اجتماعية عربية RTL مبنية على Vite وSupabase.

## الميزات الموجودة في هذه النسخة

- تسجيل ودخول بالبريد وكلمة المرور عبر Supabase Auth.
- ملفات شخصية: الاسم الظاهر، النبذة، صورة الحساب، ورابط موقع.
- منشورات نصية وصور وفيديوهات مع رفع مباشر إلى Supabase Storage.
- صفحة رئيسية بخياري «لك» و«المتابَعون».
- إعجابات وتعليقات وحفظ المنشورات ومشاركة رابط المنشور.
- متابعة وإلغاء متابعة الحسابات.
- قصص صور وفيديو تنتهي بعد 24 ساعة مع تسجيل المشاهدات.
- استكشاف الحسابات والمنشورات والبحث بالنص.
- صفحة ريلز للفيديوهات المنشورة.
- إشعارات للإعجابات والتعليقات والمتابعة والرسائل الجديدة.
- رسائل مباشرة نصية بين حسابين باستخدام الجداول الحالية.
- واجهة متجاوبة للهاتف وسطح المكتب.

## الخدمات المستخدمة

- Supabase Auth للحسابات.
- Supabase Postgres مع RLS لعزل الكتابة والتحكم بالبيانات.
- Supabase Storage في bucket باسم `dazza-social-media` للصور والفيديوهات.
- Supabase Realtime لتحديثات المنشورات والإشعارات والرسائل.
- Vercel لنشر واجهة Vite.

## حدود النسخة الحالية

هذه نسخة اجتماعية أساسية قابلة للتوسعة وليست مطابقة لكل خدمات Instagram. لا تتضمن حالياً بثاً مباشراً، مكالمات صوت/فيديو، رسائل وسائط، حسابات خاصة وطلبات متابعة، رسائل جماعية، إشعارات Push، محرر فيديو/فلاتر، بث Reels خوارزمي، أو مركز بلاغات ومراجعة محتوى. ترتيب «لك» حالياً زمني وليس توصية خوارزمية. القصص حالياً صور وفيديو بمدة 24 ساعة. الوسائط داخل منشورات وقصص دَزّة عامة عبر روابط التخزين؛ لا ترفع ملفات خاصة أو حساسة.

## حدود الرفع

الملفات المقبولة: JPEG وPNG وWEBP وGIF وMP4 وWEBM. الحد الأعلى 50 ميغابايت للملف. لا ينفّذ المتصفح ضغط فيديو أو تحويل صيغ تلقائياً.

## متغيرات Vercel

- `VITE_SUPABASE_URL=https://jdtvkapmroqgerqsnjwe.supabase.co`
- `VITE_SUPABASE_ANON_KEY` أو المفتاح العام Publishable.

لا تضع مفتاح `service_role` أو أي مفتاح سري في كود المتصفح.

## التشغيل محلياً

```bash
cd web
npm install
npm run dev
```

## ملاحظات الأمان

كل جداول الشبكة الاجتماعية الجديدة مفعّل عليها RLS، وكل سياسات الكتابة تربط السجل بالمستخدم الموثق. سياسات تخزين الملفات تقصر الرفع والتعديل والحذف على مجلد صاحب الحساب. يجب مراجعة Supabase Security Advisors وإعداد حماية كلمات المرور المسربة وSMTP قبل الاستخدام العام.
