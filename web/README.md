# DAZZA Web

واجهة دَزّة مبنية على Vite وSupabase المجاني: تسجيل بالبريد وكلمة مرور، ملفات شخصية، محادثات مباشرة ورسائل لحظية عبر Supabase Realtime.

## إعداد Vercel
أضف متغيري البيئة:
- `VITE_SUPABASE_URL=https://jdtvkapmroqgerqsnjwe.supabase.co`
- `VITE_SUPABASE_ANON_KEY` أو `VITE_SUPABASE_PUBLISHABLE_KEY`: مفتاح publishable الخاص بالمشروع. لا تضع service_role أو secret key في الواجهة.

القيم الافتراضية في الواجهة تشير إلى مشروع Supabase الحالي ومفتاح publishable العام، ويمكن استبدالها بمتغيرات Vercel.

## المصادقة والبريد
تستخدم الواجهة Supabase Auth مع البريد وكلمة المرور. قد يطلب Supabase تأكيد البريد قبل أول دخول. مرسل البريد الافتراضي في Supabase محدود ومخصص للاختبار، وقد لا يرسل إلى عناوين عامة بمعدل مرتفع. لضمان وصول الرسائل للمستخدمين لاحقاً، يلزم مزود SMTP موثوق. لا نحتاج Resend أو نطاقاً مخصصاً في هذه النسخة إذا كان تأكيد البريد معطلاً من إعدادات Auth، لكن تعطيله يقلل ضمان التحقق من ملكية البريد.

## قاعدة البيانات
تم إنشاء الجداول والسياسات:
- profiles
- conversations
- conversation_members
- messages

جميع الجداول محمية بـ RLS، وتُسمح قراءة الرسائل وإرسالها لأعضاء المحادثة فقط. الرسائل تستخدم HTTPS وتخزين Supabase؛ **هذه النسخة لا توفر تشفيراً تاماً بين الطرفين (E2EE)**. لا تستخدمها حالياً لتبادل أسرار أو معلومات حساسة.

## التشغيل
```bash
cd web
npm install
npm run dev
```

المحادثات والرسائل المباشرة مدعومة في هذه النسخة. المكالمات الصوتية/الفيديو والملفات والمجموعات والإشعارات ليست مفعلة بعد.
