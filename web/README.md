# DAZZA Web

واجهة ويب أولية مرتبطة ببوابة DAZZA الحالية وخادم Matrix. هذه ليست نسخة إنتاجية بعد.

## المتطلبات

- Node.js 20 أو أحدث.
- بوابة DAZZA منشورة عبر HTTPS ومهيأة بمزوّد Twilio Verify.
- خادم Matrix/Synapse منشور عبر HTTPS.
- أصل الويب مضاف إلى إعداد CORS في بوابة الهوية (راجع إعداد الخادم).

## التشغيل

```bash
cd web
cp .env.example .env.local
# عدّل العنوانين إلى نطاقي API وMatrix الحقيقيين
npm install
npm run dev
```

## البناء

```bash
npm run build
```

## ما يعمل في هذه المرحلة

- طلب OTP حقيقي عبر endpoint الحالي `/v1/auth/start`.
- التحقق وإنشاء/استرجاع جلسة Matrix عبر `/v1/auth/verify`.
- تهيئة Matrix Rust Crypto قبل عرض المحادثات.
- عرض الغرف، البحث المحلي، إنشاء محادثة مباشرة، وإرسال النصوص فقط في الغرف المشفّرة.

## قيود معروفة قبل النشر

- بوابة الهوية الحالية تعتمد رقم الهاتف وTwilio Verify؛ تسجيل البريد الإلكتروني غير موجود في الخادم الحالي.
- جلسات الويب وتخزين مفاتيح التشفير تحتاج اختباراً عملياً على متصفحات متعددة، خصوصاً بعد تسجيل الخروج أو فقدان بيانات المتصفح.
- لا يوجد دعم ويب للمرفقات أو المكالمات أو الحالات أو الإشعارات حالياً.
- لا يوجد نطاق نشر أو أسرار إنتاجية ضمن المستودع. لا تضع مفاتيح Twilio أو أسرار الخادم في متغيرات `VITE_*`.
- يجب إعداد CORS لأصل النشر الفعلي في بوابة الهوية قبل أن يتمكن المتصفح من الاتصال بها.
- لا تعتبر هذه النسخة جاهزة للاستخدام مع بيانات حساسة قبل اختبار جهازين والتحقق من مفاتيح التشفير والاستعادة.
