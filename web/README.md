# دَزّة | DAZZA Cosmos

تطبيق اجتماعي عربي RTL يجمع التواصل والمحتوى والألعاب والأدوات اليومية في واجهة واحدة. مبني بـ Vite وSupabase، ومهيأ للتثبيت كتطبيق ويب تقدمي (PWA).

## التواصل والمجتمع

- تسجيل حساب ودخول بالبريد وكلمة المرور.
- استعادة كلمة المرور وتعيين كلمة مرور جديدة.
- ملفات شخصية ونبذة وصورة حساب.
- منشورات نصية وصور وفيديوهات.
- قصص تنتهي بعد 24 ساعة.
- إعجابات وتعليقات ومتابعة وحفظ المنشورات.
- استكشاف الحسابات والبحث.
- ريلز للفيديوهات المنشورة.
- إشعارات للإعجابات والتعليقات والمتابعة والرسائل.
- محادثات مباشرة نصية بين المستخدمين.
- مظهر ليلي فضائي ومظهر نهاري.

## مركز الألعاب — مجاني

ألعاب تعمل محلياً داخل المتصفح ولا تحتاج مفاتيح API أو اشتراكاً:
- ذاكرة الكواكب: مطابقة الأزواج.
- إكس أو: خصم كمبيوتر يستخدم Minimax.
- 2048: دمج الأرقام ولوحة تحكم مناسبة للموبايل.
- حجر ورقة مقص.
- اختبار معلومات من أسئلة عربية قصيرة.

النتائج الأفضل تُحفظ محلياً على الجهاز. لا يوجد حالياً نظام ترتيب عالمي أو مزامنة نتائج بين الحسابات.

## مختبر الأدوات — مجاني

- حاسبة للعمليات الأساسية.
- تحويل وحدات الطول والكتلة والحرارة.
- ملاحظات محلية خاصة بالجهاز.
- مؤقت تركيز 25 دقيقة.
- عداد كلمات وحروف.

الملاحظات ونتائج الألعاب وإعداد المظهر تُخزّن في مساحة المتصفح المحلي ولا تُرفع إلى قاعدة البيانات.

## تطبيق ويب قابل للتثبيت

يحتوي على manifest وservice worker للتخزين المؤقت لواجهة التطبيق وملفاتها الأساسية. يمكن تثبيته من المتصفح على الأجهزة المدعومة. التخزين المؤقت لا يعني أن الحسابات أو المنشورات أو الرسائل تعمل دون إنترنت؛ بيانات Supabase تتطلب اتصالاً.

## التقنية

- Supabase Auth للحسابات.
- Supabase Postgres مع RLS للبيانات.
- Supabase Storage لصور المنشورات والقصص وصور الحساب.
- Supabase Realtime لتحديثات الرسائل والإشعارات.
- Vite لبناء الواجهة، وVercel للاستضافة.
- `@supabase/supabase-js` مثبت على الإصدار المستقر 2.118.0.
- Vite 6.4.5 ضمن خط التحديثات المدعوم.

## حدود النسخة الحالية

هذه منصة اجتماعية متعددة الميزات وليست نسخة مطابقة لكل وظائف Instagram أو Discord أو TikTok. لا تتضمن حالياً بثاً مباشراً، مكالمات صوت/فيديو، رسائل وسائط أو مجموعات، حسابات خاصة وطلبات متابعة، إشعارات Push، خوارزمية Reels، فلاتر ومحرر فيديو، أو نظاماً متكاملاً للبلاغات والإشراف. الترتيب في «لك» زمني.

الوسائط في bucket الحالي عامة عبر روابط التخزين؛ لا ترفع ملفات خاصة أو حساسة. حدود الرفع: JPEG وPNG وWEBP وGIF وMP4 وWEBM، بحد أقصى 50MB للملف.

## إعداد Vercel

- `VITE_SUPABASE_URL=https://jdtvkapmroqgerqsnjwe.supabase.co`
- `VITE_SUPABASE_ANON_KEY` أو المفتاح العام Publishable.

لا تضع مفتاح `service_role` أو أي مفتاح سري داخل الواجهة.

## التشغيل والاختبار

```bash
cd web
npm install
npm test
npm run build
npm run dev
```

اختبارات الواجهة الحالية تتحقق من أسماء حقول المصادقة، قراءة FormData، الخروج المحلي، استعادة كلمة المرور، وجود مركز الألعاب، وعزل التخزين المؤقت عن طلبات النطاقات الخارجية.

## ملاحظات أمان

سياسات RLS مفعّلة على جداول المحتوى، وتقيّد الكتابة بهوية المستخدم. سياسات تخزين الملفات تقيّد الرفع والتعديل والحذف بمجلد صاحب الحساب. قبل الاستخدام العام يجب تفعيل حماية كلمات المرور المسرّبة، إعداد SMTP موثوق، مراجعة روابط إعادة التوجيه، وتفعيل آليات الإبلاغ والإشراف.
